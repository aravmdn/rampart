# Business Model

Rampart is open source at the local product layer and can stay usable without a cloud dependency.

## Free local product

- Local sandboxing
- Local session history
- Policy profiles
- No required account
- No required cloud service

## Paid team layer

- Shared policy coordination
- Aggregated audit visibility
- Alerts and team-facing history
- Hosted controls for organizations that want coordination beyond one machine

## Product boundary

The public repo should focus on the local enforcement loop and the trust model. Hosted features belong in separate docs and should not require private working notes in the public repository.
