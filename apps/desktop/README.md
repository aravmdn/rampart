# Desktop shell

Rampart desktop now runs as a Tauri app with a React + Vite frontend shell.

## Commands

- `pnpm dev`
- `pnpm build`
- `pnpm build:web`
- `pnpm typecheck`
- `pnpm test`

## Structure

- `src/` holds the React desktop shell
- `src-tauri/` holds the native Tauri host crate and config
